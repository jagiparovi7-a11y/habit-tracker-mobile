# Пайдалы әдеттерді қалыптастыру мобильді қосымшасы

Бұл мобильді қосымша пайдаланушыларға пайдалы әдеттерді жоспарлауға, күнделікті орындауға және прогресті бақылауға көмектеседі. Жүйе әдеттерді тіркеп, олардың орындалу тарихын сақтайды.

## Мақсаты
Пайдаланушыға пайдалы әдеттерді жүйелі қалыптастыру және орындалуын бақылау мүмкіндігін беру.

## Пайдаланушылар
- Тіркелген пайдаланушы
- Жүйе әкімшісі

## Талаптар
1. Пайдаланушы аккаунт жасап, жүйеге кіре алады.
2. Пайдаланушы жаңа әдеттің атауын және сипаттамасын енгізеді.
3. Пайдаланушы әдеттің қайталану жиілігін таңдайды.
4. Жүйе міндетті өрістердің толтырылғанын тексереді.
5. Жүйе жарамды әдетті деректер базасына сақтайды.
6. Жүйе қате деректер кезінде түсінікті ескерту көрсетеді.
7. Пайдаланушы әдеттер тізімін және орындалу тарихын қарай алады.
8. Пайдаланушы әдеттің күнделікті орындалуын белгілей алады.

## Негізгі сценарий
**Жаңа пайдалы әдет қосу:** пайдаланушы әдетті енгізеді, жүйе деректерді тексереді, жарамды болса деректер базасына сақтайды, болмаса қате көрсетеді.
